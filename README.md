# 4d-list-toolbox
Tools and utilities for working with lists in 4D.

# How to use it:
Open 4D List ToolBox.html in your browser.

Choose Open JSON and select your lists.json file.

Select a list on the left and an entry in the middle.

Edit properties on the right. Add, remove, rename, reorder, duplicate, and create child entries with the bottom controls. 

Undo and redo are in the top toolbar.

Save JSON writes back when the browser provides file access and the file was opened through the picker. 
Otherwise it downloads a JSON copy. 
Drag-and-drop always uses download saving. 
Keep the downloaded file before closing.

All file editing runs on your device. Your JSON data is not bundled with this app or sent to a server. 
Unknown properties are retained. 
Styles and actions can be edited through raw JSON properties; dedicated controls were not added because their schema was not confirmed from the supplied file.
